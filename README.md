# Money Tracker
## Description
This is a simple program that allows you to track how much money you have available for the week. It informs you if you can keep spending and just how much or how much you are behind and must make up.

## How to run
```
python3 app.py
or
python app.py
```

## Example Interaction
```
How much did you spend this week on groceries?
13.12
How much did you earn this week from working?
12.11
You have spent $1.01 more than you have earned this week.
```
